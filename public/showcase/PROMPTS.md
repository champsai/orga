# Showcase photos: prompts for ChatGPT or Gemini

The client site shows a drawn illustration (`<id>.svg`) for each past event. To replace one with a
photo-style image, generate it in ChatGPT (image generation) or Gemini, save it in this folder as
`<id>.jpg` (or `.png` / `.webp`), and refresh the page. The site picks the photo up automatically;
no code change and no restart needed.

Tips: ask for **landscape 16:10** (about 1600×1000). Keep faces small or blurred, since these are
illustrations of fictional events. Add the same style line to every prompt so the set looks consistent:

> Style: editorial event photography, wide shot, cinematic warm light, shallow depth of field, rich but natural colours, no text, no logos, no watermark, landscape 16:10.
