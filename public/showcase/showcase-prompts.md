# Orga showcase image prompts

Generated using the built-in image generation tool. All scenes depict fictional events.

Each final prompt combines the common introduction, its scene below, and the common style.

## Common introduction

Use case: photorealistic-natural. Asset type: fictional event showcase photograph for an event-planning website. Generate one finished image only. Landscape 16:10 composition, approximately 1600×1000.

## Common style

Shared series style: editorial event photography, wide shot, cinematic warm practical light where appropriate while preserving the scene's specific coloured lighting, shallow depth of field, rich but natural colours, believable photographic materials and perspective. Faces small or softly blurred. No readable text, no logos, no watermark. This is a photograph-style scene, not a poster, illustration, collage, contact sheet, or interface.
